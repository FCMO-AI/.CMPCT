02 / WHY IT CAN WIN

The archive is compiled as an information graph.

CMPCT searches for exact relationships between required objects, chooses physical roots and records deterministic reconstruction paths while keeping locality, integrity and recovery costs explicit.

^

01

Exact identity

Identical content can converge on one authenticated physical root without collapsing independent logical paths.

02

Relationship-aware storage

Required objects can reuse exact compressed structure instead of paying duplicate storage merely because filenames differ.

03

Selective access

Read the object requested instead of making one giant archive-wide decompression event the only route to useful bytes.

04

Bounded context

Cross-file context is auditioned and constrained so a size win cannot silently create unbounded read work.

05

Integrity

Indexes and physical data carry explicit checks; success is not defined as “the decompressor did not complain.”

06

Physical recovery

Redundant authenticated metadata exists as an actual reader path, not a disaster-recovery promise written in prose.
