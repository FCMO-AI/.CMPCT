# CMPCT terminology

## Version naming invariant

CMPCT has **no "B" release series**.

All project-version references use **V / v**, meaning **version**: for example, **v0.29**, **v0.30**, or informally **V29 / V30** when the leading zero is omitted in speech.

If a transcript, chat-derived note, issue, benchmark discussion, agent handoff, or other CMPCT-related material contains forms such as **B29**, **B30**, **B0.29**, **B0.30**, or refers to a CMPCT **"B series"**, treat that wording as an **audio-transcription error that misheard spoken "V" as "B"**. Normalize it to the corresponding **V / v version reference** unless there is explicit non-CMPCT context proving that the letter B means something else.

This is a terminology correction only; it does not rename historical artifacts or alter hashes, benchmark data, format revisions, or version identities.
