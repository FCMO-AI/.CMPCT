## Frozen Builder mechanism

The productization candidate is `experiments.entropygraph_v030_prefixgraph_process_executor.PrefixGraphProcessExecutor` and must retain all of these properties:

1. **exact semantic owner** — only `experiments._v030_canonical_prefixgraph.build(source, archive)` is accepted;
2. **disposable child lifetime** — the child completes and exits before the parent proceeds to the remaining candidate tournament; overlap is not allowed because early child death is the supported memory mechanism;
3. **fixed raw-prefix level 15** — only `_prefix_codec` changes from the canonical level-19 raw-content dictionary compressor to the same dictionary bytes at level 15; direct payload compression, anchor nomination, candidate pricing, tie law and grammar remain unchanged;

5. **bounded execution** — child wall time is bounded by `<=180 s`; timeout/nonzero/malformed receipt is an error;
6. **fail-closed artifact custody** — failure removes any partial destination; success requires physical size and SHA-256 to match the child receipt before statistics are accepted;
7. **one-shot contract** — one executor instance may accept exactly one PrefixGraph submission.

Importing the candidate module may not initialize or mutate canonical state. Canonical PrefixGraph is imported and level-overridden only in the disposable child.
