# r25 Shifted post-PrefixGraph G0-G4 audition oracle preregistration

Status: **FROZEN BEFORE RESULT-BEARING EXECUTION / FORGE R1 O0 HEADROOM ONLY / NO RELEASE CREDIT**

## Question

On the exact repaired Shifted product target, how much complete create-time headroom is exported solely by continuing the G0-G4 audition **after** the isolated PrefixGraph candidate has already been fully materialized and the child has exited?

The current product must run G0-G4 because PrefixGraph existence alone is not a legal stopping proof: a smaller G0-G4 candidate may exist. This experiment therefore asks only whether that losing audition is large enough to justify engineering a deployable lower-bound/admission proof. It does **not** authorize skipping G0-G4 in shipping code.

## Arms

Run **5 alternating paired fresh-process repetitions** with order:

1. control -> oracle,
2. oracle -> control,
3. control -> oracle,
4. oracle -> control,
5. control -> oracle.

Build a research-only product-composition arm that changes **one thing only**: after exact PrefixGraph construction, the experiment is gifted the discovery fact that **PrefixGraph is the winning r25 family for this exact frozen target**, and therefore does not execute G0-G4.

The oracle must still pay for:

## Interpretation after a positive result

A positive O0 result does **not** permit a product fast path. It only establishes enough Addressable Opportunity Mass in the required Shifted product row to justify one deployable successor.

The successor must provide a **sound pre-G0-G4 stopping proof or cheap audition bound** whose own computation/control cost is fully charged. It may use information already produced by profile preparation, r24 construction or PrefixGraph, but it may not key on benchmark identity/name/tree hash, and it may not assume historical G0-G4 losses generalize. It must fail open to the full G0-G4 tournament when uncertain.

The deployable mechanism then owes global carrying cost: nomination/audition cost on non-Shifted workloads, parser/reader impact if any metadata is added, fuzz/recovery behavior, native/platform parity, and portfolio complexity. Prefer a concept-compressing bound that can subsume other losing-candidate work rather than a Shifted-only exception.

## Interpretation after a negative result

A valid negative retires post-PrefixGraph G0-G4 audition removal as the primary Shifted create-time repair under this product composition. Do not rediscover nearby scheduler/cutoff variants without a new causal reopening predicate. Shifted effort should move to a different measured owner such as PrefixGraph child startup/import or the G0-G4 shared baseline itself.

## Strongest hostile-review question

The experiment is intentionally generous: it gifts the exact winning r25 family. The strongest surviving criticism of a positive result will therefore be, "can the product know this cheaply and safely before paying G0-G4?" Until the deployable successor answers that question under exact product bytes, a large oracle win remains headroom—not a release improvement.
