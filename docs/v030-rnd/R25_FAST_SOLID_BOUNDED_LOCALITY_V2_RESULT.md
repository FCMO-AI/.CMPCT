The experiment proves a real but fragile Pareto point: bounded-locality exact reconstruction can be simultaneously smaller and much faster to create than both competitors on two fixed rows. The size margins versus Zstd19 are so small, however, that ordinary representation metadata, generic admission, parser complexity, or cross-platform productization cost could erase the practical value.
