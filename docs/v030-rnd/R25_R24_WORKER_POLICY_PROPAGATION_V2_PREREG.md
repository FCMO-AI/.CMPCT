## Diagnosis

Forge class: **D1/D2 implementation/execution-policy propagation defect**, R0 causal attribution first.

`src/cmpct/builder.py` states that ordered `Executor.map` makes one-worker construction a byte-for-byte oracle for multithreaded construction. However, the v0.30 release path extends `TEXT_EXT` with `.bin` through a `threading.local()` release policy. `_encode_candidate()` re-queries `TEXT_EXT` inside encoder worker threads. Python thread-local state is not inherited by those threads.

This creates a precise pre-result hypothesis:

> The 4-worker shipping path loses `.bin` dictionary eligibility inside encoder threads, while the single-worker path executes in the policy-owning thread. If that is the sole cause of v1's byte drift, a 4-worker diagnostic arm that exposes the same already-active `.bin` eligibility to encoder workers must reproduce the single-worker archive exactly.

This is a policy-propagation test, not permission to force single-threaded production encoding.

## Frozen target

`resemblance_hostile_v1 / 01_shifted_versions`, regenerated by the current deterministic v0.30 performance corpus machinery.

Three fresh-process arms, three rounds with alternating order:

1. `inherited`: exact shipping r24 construction;
2. `single`: exact shipping r24 construction with `Builder(workers=1)`;

The propagated arm changes no archive grammar, compression level, dictionary trainer, source shape, pack policy, locality law, reader behavior, recovery behavior or release threshold. It only removes the thread-local visibility difference inside this diagnostic process.

## Identity and correctness law

Every arm must strongly verify to the same user tree. The decisive causal identity is:

- `single` and `propagated` complete archive bytes, SHA-256 and stable build stats are exact;
- `single` and `propagated` both report a live dictionary;
- `inherited` remains byte-distinct and reports a dead dictionary.

Worker counts are recorded explicitly. `propagated` must use more than one encoder worker or the experiment is invalid.
