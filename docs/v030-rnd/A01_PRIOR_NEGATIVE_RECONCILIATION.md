# A01 prior-negative reconciliation

Status: **decision constraint for A01 O1; no new product claim**.

The accepted A01 O0 latent-root result must not be interpreted in isolation from the preserved v0.29 shared-context negatives.

## Relevant inherited negative

`docs/MOSAIC_V029_SHARED_DICTIONARY_ORACLE.md` records a frozen rejection of an archive-global trained Zstandard dictionary. That mechanism bought only **6,340 net bytes** on its hostile aggregate and failed its preregistered **128 KiB** net-saving promotion threshold. The subsequent one-hop reference-context oracle found **zero admissible profitable targets**. Those results remain valid and are not weakened by A01.

## Why A01 is not a replay

The old shared-dictionary family changes entropy-coder context for otherwise independent physical records. A01 changes the **ownership/reconstruction model**: it stores one complete synthetic physical root and reconstructs each member through an exact charged residual from that root.

A dictionary is a bounded statistical context dependency. A latent root is an explanatory object whose bytes may correspond to no historical member. They can overlap in intuition (“shared information not equal to a file”) but they charge and expose different information.

Therefore the A01 O0 result is scientifically distinct, but the old negative raises the bar for transfer: a real-data A01 campaign must prove that it is exploiting family reconstruction structure rather than merely rediscovering weak cross-record context under a more generous synthetic generator.

## O1 constraint

A01 may advance only if the next generator-distinct / real-family test includes a control that separates latent-root residual savings from shared entropy-context savings. At minimum, for every family that shows a latent-root win, compare against:

1. strongest observed-root / canonical multi-root representation available;
2. direct/solid terminal compression;
3. a charged shared-dictionary or equivalent shared-context control when enough samples exist.

If shared context captures essentially all of the latent-root gain, narrow A01 to an entropy-context mechanism and respect the prior v0.29 negative. If the latent root retains material complete-description savings beyond shared context, the ownership-model interpretation survives.

No threshold from the old dictionary experiment is transplanted into A01. The old result is a causal alternative and negative constraint, not a benchmark to game.
