This frozen cohort attacked a different temporal/versioned regime: local edits *inside* the second version.

## Causal interpretation

This negative does **not** overturn the earlier shift/starvation evidence. Epoch-min still retained all 35 hard-rescue rows, all 96 insertion-shift mature-positive rows, and the charged MIY corpus. The failure is narrower: internally edited versioned data can contain a useful mature-minimizer relation that is not represented by sparse anchors plus one rightmost minimum per starvation epoch.

The causal missing statistic is not yet established. Therefore no threshold, epoch length, mask or capacity is changed here. Doing so before localizing the exact mature-only nomination would be parameter fishing.

The mature rolling minimizer is also not reinstated as a permanent separate mechanism. ONE law requires asking which predictive relationship it exploited in this row and whether that relationship can be expressed by a smaller sufficient statistic inside the same fused encoder discovery model.

## Scoped negative constraint

**Tested regime:** random 64 KiB / 256 KiB bases paired with an internally edited second version; 1/4/16/64 independently placed byte substitutions; fixed ONE observer + exact mature minimizer versus fixed observer + sparse Gear/epoch-min candidate.

**Observed constraint:** scalar starvation-epoch minima are not sufficient, by themselves, to subsume every mature rolling-minimizer opportunity in internally edited temporal/versioned data.

**Do not generalize to:** all versioned data, all edited data, or all shift-invariant reuse. The prior insertion-shift and hard-rescue transfer results remain valid.

**Reopening predicate:** mechanism-level evidence localizes the missed mature nomination and demonstrates a bounded additional statistic/relationship that recovers it without recreating the full 4,096-position sliding-minimum machinery or introducing a reader-visible legacy mechanism.
