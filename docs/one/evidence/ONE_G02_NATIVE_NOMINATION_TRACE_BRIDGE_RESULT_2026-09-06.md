## Hostile Reviewer

This result must not be used as writer-speed authority. Local fixed-window auditions, index/event consumption, exact 64-byte witness checks, extension proof, and nomination accounting still execute in Python. Timing a Python nominator followed by a native relation proof would mix runtimes and could hide or fabricate the actual cost owner.

The bridge therefore closes only the semantic handoff: native selector positions are sufficient to reproduce the existing nomination policy exactly.

## Decision / next falsifier

A later fused observer must remove that extra pass before claiming a memory-bandwidth-oriented writer path.
