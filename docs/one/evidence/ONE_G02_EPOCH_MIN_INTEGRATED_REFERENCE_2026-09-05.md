## Causal interpretation

The earlier recurrence-level speedup did not disappear once semantic index/proof work was charged in the same reference timing boundary. On the tested large and shifted regimes, the dominant advantage survives at the complete discovery-path level. This strengthens the causal claim that maintaining an exact 4,096-position rolling minimum is unnecessary encoder work for the transferred opportunity family; the scalar starvation-epoch statistic is not merely moving cost into Python bookkeeping.

Forge diagnosis for the inherited mature path is therefore primarily **D2/D3**: execution/search architecture was retaining and updating substantially more historical selector state than the demonstrated opportunity requires. The epoch-min intervention is an algorithmic/search simplification (R3) plus a pending fused execution implementation (R2), not a reader representation change.
