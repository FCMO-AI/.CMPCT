# ONE-G0.2 relation writer envelope — preregistration

Date: 2026-09-09
Experimental line: ONE-G0.2
Authoritative branch: `research/cmpct1`

## Mission Lock

The promoted relation line has already established three narrower facts: cheap block-cadence relation evidence can avoid the prior fixed-grid alias; exact relation seeds can grow to maximal verified spans; and a bounded witness can transfer from shared 64-byte observation into ordinary `add8`/`xor` + Surprise/concat ONE Programs. Those facts do **not** establish that relation discovery earns its complete writer cost.

The preferred current research-writer emission shape is the root-hash-charged direct final-buffer emitter. This experiment therefore moves upward in scope and asks whether relation discovery still has positive system economics after charging the complete research writer envelope that this candidate actually uses.

This is not a detector-accuracy benchmark and not a new reader mechanism. No reader-visible opcode, stored semantic rule, integrity rule, resource cap, or comparator setting may change to make it pass.

## Referee / falsifiable hypothesis

Hypothesis: on genuinely related versioned data, shared block observation -> bounded relation witness -> exact maximal-span proof -> generic ONE Program can remove enough final stored information to justify its incremental creation CPU, while hostile/no-opportunity inputs remain cheap enough that the writer can refuse the search without large waste.

Disproof is any of:

- semantic/root mismatch;
- a hostile negative admitting relation bytes;
- positive wire savings that disappear once emitted as canonical ONE;
- false nomination proof work exceeding the frozen bound;
- incremental relation work whose marginal information yield falls below the frozen floor;
- no-opportunity overhead exceeding the frozen ceiling;
- discovery state or source/proof traffic exceeding the frozen resource law.

A HOLD is a useful result. Do not tune thresholds after hosted evidence.

## Arms

Both arms charge, inside every timed call:

1. SHA-256 identity of the complete input object;
2. generic Program shape validation;
3. direct final-buffer canonical ONE emission;
4. canonical decode/reference reconstruction outside timing as a semantic oracle.

### Baseline

Direct canonical emission of the literal generic ONE Program for the exact same object. It performs no relation discovery.

### Candidate

The same root hashing, validation and direct final-buffer emission, plus:

1. one forward 64-byte-cadence relation observation over the object;
2. bounded witness grouping;
3. exact maximal-span verification for nominated `add8`/`xor` relations;
4. generic Program construction from accepted spans and Surprise cracks/tails.

The candidate may not reuse a precomputed root hash, skip validation, use the helper emitter, or authorize a relation from a sketch alone. Exact proof is mandatory.

The baseline is intentionally the relation-disabled generic direct writer, not the older helper emitter. The experiment therefore asks what predictive relation discovery itself costs and earns under the currently preferred emission principle.

## Frozen matrix

Sizes:

- 64 KiB
- 256 KiB
- 1 MiB

Families:

Positive:

- `add8_versioned`
- `xor_versioned`
- `add8_sparse_cracks`
- `xor_sparse_cracks`

Hostile/control:

- `exact_repeat`
- `random`
- `compressed_like`
- `probe_false_positive`

The positive and hostile generators reuse the already-audited relation-witness semantics. `compressed_like` is deterministic zlib-compressed pseudo-random payload expanded/truncated deterministically to the requested object size; it is a no-opportunity carrying-cost control, not a claim about all media.

Use 9 paired alternating A/B-B/A repetitions per row. Timing is wall and process CPU. GC state must be equal between arms. The same generated bytes are reused by both arms.

## Frozen accounting

For every row preserve:

- exact canonical wire bytes for baseline and candidate;
- exact reconstructed/root equality;
- bytes saved versus baseline;
- wall and CPU medians for both arms;
- candidate/baseline wall and CPU ratio;
- incremental CPU seconds;
- bits eliminated per positive incremental CPU second;
- source scan bytes;
- probe bytes;
- exact proof bytes;
- accepted relation bytes;
- modeled retained observation state;
- relation witnesses retained;
- final Program node count;
- reader work/materialization from the ordinary evaluator.

Modeled observation state is not CPython RSS and must not be reported as such.

## Frozen decision law

INVALIDATE if any semantic/root/canonical decode mismatch occurs, or if any negative/control admits relation bytes.

Otherwise ADVANCE only if all hold:

1. every positive row saves at least **25%** canonical wire versus the literal direct-writer baseline;
2. every positive row accepts relation bytes and chooses the expected nonzero Law/value;
3. median positive marginal yield is at least **20 Mbit eliminated / incremental CPU second**; rows whose candidate is faster than baseline are treated as infinite positive marginal yield rather than producing a negative denominator;
4. every `probe_false_positive` row spends at most **8192 exact proof bytes**;
5. every row charges exactly **1.0x source observation scan bytes** for the candidate and at most **0.05x input bytes** as relation probes;
6. modeled retained observation state is at most **0.60x input bytes**;
7. median control candidate/baseline CPU ratio is at most **1.35x** and no individual control exceeds **1.75x**.

If semantics are exact but any performance/resource law fails, HOLD.

The control-overhead law is intentionally demanding: a writer that spends large CPU proving there is no useful relation has failed the project even if positive density is excellent.

## Hostile-review boundaries

- This is still Python research-writer evidence. Passing does not establish product-native create throughput or RSS.
- The relation observer currently assumes contiguous version geometry when turning witness offsets into parent/child coordinates. That is acceptable for this transfer/economics falsifier, not arbitrary archive segmentation authority.
- The bounded witness map can saturate; late relations beyond its horizon remain reopening debt even if this matrix passes.
- `compressed_like` is one deterministic hostile family, not complete already-compressed/media coverage.
- Authentication/container placement, filesystem fidelity, durability/recovery and authenticated selective-access proof traffic remain outside this envelope; do not call this full product ingest.
- The September 11 same-input 15-workload Genesis comparator gate is separate and cannot be replaced by this result.

## Interpretation

An ADVANCE would mean only that relation discovery has credible research-writer economics under the charged boundary above and merits integration into a common Law-admission budget. A HOLD means the representation insight survives but writer-side observation/proof/state must be made cheaper—preferably by native/shared observation or better opportunity pruning—before relation discovery is carried broadly.
