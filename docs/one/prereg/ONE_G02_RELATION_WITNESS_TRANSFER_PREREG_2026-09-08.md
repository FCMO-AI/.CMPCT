# ONE-G0.2 Relation Witness Transfer — preregistration

## Mission lock
Test whether the promoted 64-byte observation cadence can become an actionable writer handoff rather than a whole-file classifier.  The candidate must retain enough bounded evidence to identify an existing ONE relation Law (`add8` or `xor`), its non-zero value, and parent/child geometry without a second discovery scan.  Exact verification remains authoritative.

## Hypothesis
Transform-invariant three-probe block signatures can nominate non-periodic versioned relations in one forward pass.  Passing those witnesses directly to bounded maximal span growth will produce an exact generic ONE Program with <=0.60x literal wire on relation-bearing version pairs, while hostile probe-only aliases spend bounded proof work and fall back to literal representation.

## Frozen matrix
Sizes: 64 KiB, 256 KiB, 1 MiB. Families: non-periodic add8-versioned, XOR-versioned, both with sparse cracks, exact-repeat control, random control, and a probe-only false-positive adversary.  Positive parents are deterministic pseudo-random bytes, so a relation win cannot be credited to the periodic exact-reuse behavior of the earlier ramp/lag-64 synthetic cases.

## Frozen law
- all reconstructed roots must equal source exactly;
- observer source scan is exactly 1.0x input;
- block probes consume <=0.05x input bytes beyond the already-paid block cadence;
- modeled bounded observation state <=0.60x input at every scale;
- each positive row must identify the oracle operation/value, accept relation bytes, and emit <=0.60x literal wire;
- no negative row may accept relation bytes;
- probe-only false positives may spend at most 8192 exact proof bytes;
- relation values and geometry must come from the observation record; a second discovery scan is forbidden.

Writer wall/CPU and bits eliminated per CPU second are recorded, but this Python reference implementation cannot establish the final native carrying-cost gate.  ADVANCE means the handoff principle and final-byte economics survive; a separate native transfer gate is required before speed promotion.
