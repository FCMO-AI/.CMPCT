## Falsifiable hypothesis

On an independently generated deterministic temporal-family corpus, an OpenSSL/C implementation of the same underlying representation should retain the large setup advantage and keep authenticated selective-read work close to independent per-version AuthTrees.

If the native shared path exceeds **1.20x** independent selective-read elapsed on any tested family, the claim that shared representation authentication is a bounded-speed Pareto fails for this transfer regime. These are disproof thresholds, not product targets.

## Frozen corpus and semantics

- root sizes: 64 KiB and 256 KiB;
- three deterministic independent bases per size, generated by a fixed xorshift64 stream;
- eight edited versions per basis;
- mutation counts cycle through 1, 4, 16 and 64 for the eight versions;
- exact translation Law: target equals basis except for explicit Surprise positions/literals;
- Surprise wire remains count ULEB followed by position-delta ULEB + literal byte;
- basis and independent roots use the existing domain-separated SHA-256 AuthTree semantics with 80-byte leaves;
- descriptor authentication uses the existing generic 40-byte control + Surprise digest leaf and packed quaternary V=8 tree shape;
- selective request: 4 KiB at one deterministic non-leaf-aligned interior start;
- reader performs no discovery.

This is deliberately an independent transfer corpus rather than replaying the CPython corpus. A pass therefore tests mechanism portability, not benchmark memorization.

## Charged work

Independent comparator:

- nine complete logical roots are persisted (basis + eight versions);
- every root carries its own non-root AuthTree hashes;
- setup builds nine AuthTrees;
- each selective version read verifies the requested cone against that version's root.

Shared ONE candidate:

- basis is persisted once with one AuthTree;
- eight 40-byte generic Law descriptors and all Surprise blobs are persisted;
- descriptor quaternary authentication hashes are charged;
- setup builds one basis AuthTree plus descriptor authentication;
- selective read verifies the basis cone and selected descriptor/Surprise, applies Surprise to the 4 KiB basis range, and byte-compares against the exact logical target.

Discovery/search is excluded symmetrically. This experiment begins after the family relation is known and therefore cannot be used to claim writer end-to-end creation speed.

## Frozen gate

Advance only if all are true:

1. every candidate reconstruction is byte exact;
2. deterministic basis-payload corruption is rejected;
3. deterministic Surprise corruption is rejected;
4. shared persisted bytes are lower than independent persisted bytes on every family;
5. shared authentication-setup elapsed ratio is <= **0.20x** on every family;
6. shared authenticated selective-read elapsed ratio is <= **1.20x** on every family.

No threshold, corpus, leaf size, version count, request size, or interpretation may change after result-bearing execution. An unfavorable result becomes scoped negative evidence.
