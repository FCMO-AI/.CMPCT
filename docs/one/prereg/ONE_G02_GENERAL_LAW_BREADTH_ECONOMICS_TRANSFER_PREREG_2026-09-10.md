# ONE-G0.2 general Law breadth economics transfer preregistration — 2026-09-10

**Mission Lock / Referee:** after represented breadth has an executable transfer falsifier, test whether compiling those same transfer relations into the single generic ONE Law + Surprise representation pays its own complete persistent-byte cost relative to the existing Surprise-only archive envelope on exactly the same tree. This is representation-economics evidence only; it must not touch the frozen Genesis corpus, v0.29, v0.30, or winner scoring.

## Falsifiable hypothesis

On the generator-distinct breadth-transfer tree defined by `benchmarks/one/one_g02_general_law_breadth_transfer.py`, the general Law archive will:

1. reconstruct the same full filesystem semantics exactly;
2. remain deterministic across repeated builds;
3. contain only the current generic reader ontology;
4. exercise Surprise, Fill, exact reuse, ADD8(constant), and XOR(constant) as independently observed through parsed reader structure;
5. use **no more complete persistent bytes** than the Surprise-only authenticated archive envelope built from the identical tree.

The stored-byte comparison must use complete returned archive bytes from both surfaces. No metadata, integrity, Program, manifest, authentication, or index bytes may be gifted or omitted.

## Disproof tests

Return HOLD if any of the following occurs:

- either archive fails exact whole-tree semantics;
- either archive is nondeterministic on an identical input;
- the Law archive does not independently expose all five represented relation classes required by the breadth falsifier;
- any reader-visible operation escapes the generic ONE ontology;
- `law_complete_stored_bytes > surprise_only_complete_stored_bytes`;
- the benchmark imports/generates/reads any Genesis workload or invokes either frozen comparator;
- comparison/scoring/winner-selection flags are anything other than false.

A size equality is permitted but counts only as non-regression, not as a density win. A strict size reduction may be reported descriptively but does not authorize a Genesis or product superiority claim.

## Required telemetry

Preserve, for both complete archives:

- stored bytes;
- SHA-256;
- logical source bytes;
- manifest bytes;
- Surprise bytes;
- control/integrity bytes;
- node count;
- exact-semantics result;
- deterministic-wire result.

For the Law archive additionally preserve relation-family counts and the parsed-reader structural proof. Report absolute byte delta and `law/surprise_only` stored-byte ratio.

CPU/wall/RSS are deliberately not promoted by this experiment; creation-resource evidence remains governed by the separately preregistered fresh-process creation/resource lanes. A density result from this experiment cannot compensate for a creation/resource regression elsewhere.

## Decision vocabulary

- `ADVANCE_BREADTH_REPRESENTATION_ECONOMICS_ONLY`: every semantic/ontology/breadth gate passes and complete Law bytes are <= complete Surprise-only bytes.
- `HOLD_BREADTH_REPRESENTATION_ECONOMICS`: any gate fails.

Neither decision promotes the Genesis candidate boundary, changes v0.29/v0.30, or executes the Genesis gate.
