# CMPCT v0.25.0 — EntropyGraph research milestone

Date: 2026-08-16

Project version: **0.25.0**  
Canonical on-disk format revision: **24 (unchanged)**

## Why this is a versioned release

This milestone materially changes the project frontier even though it does not yet change the canonical reader grammar. It publishes a reproducible EntropyGraph research engine, a hostile neutral benchmark generator, durable benchmark evidence, and a stricter version/publication discipline.

## Added

- global compressed-stream federation research;
- entropy-oriented representation inversion for exact reversible views;
- exact object interning and compact micro-pack indexing;
- adaptive bounded-context audition;
- hot/cold bounded stream roots;
- operational authenticated tail-metadata recovery in the research engine;
- explicit strong-verification path;
- deterministic-per-workload neutral/hostile corpus generator covering 10 workload families;
- durable public benchmark record preserving both wins and losses;
- CI-enforced project-version discipline for future material changes.

## Benchmark checkpoint

The fixed 10-workload suite contains 8,529 files and 172,447,100 logical bytes. The research candidate stored 90,383,940 bytes in the recorded run, versus 108,186,167 bytes for ZIP/Zstd-93 and 97,097,211 bytes for the solid tar+Zstd-19 diagnostic. CMPCT lost several individual workloads; those losses remain recorded as targets.

## Compatibility

The normal `cmpct` package continues to write/read canonical **format revision 24**. `experiments/entropygraph_v025.py` uses a research-only `CMPNX5` grammar and must not be presented as an interoperable revision-25 archive. A future project release may bump the on-disk format revision only after the new storage semantics are migrated into the canonical readers, conformance vectors, hardening gates, and portability core.

## Public-surface rule

No private development corpus identity or private artifact provenance is part of this release. Public claims are based on the synthetic neutral/hostile suite; private corpora are regression-only.
