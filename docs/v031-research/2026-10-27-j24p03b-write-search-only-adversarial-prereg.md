# J24P03b — preregistered held-out write/search-only parent perturbation

**Research scope:** same J24P03 existing-target anonymous-inode publication question, not a second project or implementation. The original primary oracle is already committed and has **local uid-65534 positive/negative results** on normally readable mode-0700 directories (2 hostile BAD publications, 2 unchallenged GOOD publications, absent linkat authentic, occupied linkat EEXIST; direct procfd rename EXDEV). This is **known evidence**, not preregistered discovery.

**New prospective hostile perturbation, before code changes:** J24F12 #559 establishes that mode-0300 Linux output directories are legitimate write/search-only targets. Does removing directory-read permission suppress the existing-target stage-name substitution? Predict **NO** when an attacker learns a stage name by the same deterministic rendezvous: W+X permits `rename(stage, quarantine)` and `open(stage, O_CREAT|O_EXCL)` without directory listing. The parent process must use `O_PATH|O_DIRECTORY` rather than O_RDONLY, and no extra privileged permissions. Under each of `os.replace` and `renameat2(RENAME_EXCHANGE)`, the independent nonroot same-UID actor should still publish BAD; unobstructed control should publish GOOD. The original 0700 cases and EEXIST/absent controls remain mandatory and unchanged.

**Falsifiers:** actor EACCES, incorrect source quarantine identity, different UID, unintended access with O_RDONLY in mode 0300, unchallenged positive failure, stage reader-to-writer control improperly substituted, kernel rename refusing for non-threat reasons, or BAD not published under actual attack. Return **INCONCLUSIVE** rather than weakening permissions or changing payload. Preserve temporary root cleanup after restoring owner-readable 0700. Committing code before this prereg or removing original 0700 controls invalidates the claim.

**Cost scope:** six additional cases maximum (4 primary held-outs plus non-reading capability/permission probes), no full CMPCT product benchmark/format/release claim, no weakened evaluator or output admission.
