2026-10-24 UTC. Supersedes **only the O1 filename ordering choice**, not the original scientific mechanism or release criteria. Original frozen O1 test SHA `eb4f87729d1e111067925685ca1903e3ee753318` uses `alias.bin`, which sorts lexicographically **before** `parent.bin`, and the existing Reader requires hardlink owner to be materialized before alias (unmerged PR #262 addresses this independent problem). The oracle asserts the same before-any-members invariant and valid inode sharing. All original O0 negative and positive tests remain byte-identical.
