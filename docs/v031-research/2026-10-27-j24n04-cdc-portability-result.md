- Original O166 and J24N02 GitHub workflows **FAIL by design on the new source blob** because they pin the parent C Git object. J24N04b proves the real Python code *when explicitly injected on Linux x64*, not that default shipping Builder exercises the new source. No installed x86 Python, real-world prevalence, broad cross-OS archive sample or packaging adoption.
