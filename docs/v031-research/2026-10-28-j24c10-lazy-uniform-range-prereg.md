## Primary question / falsifiable prediction
Can a bounded native *read-time* witness establish that every fixed-chunk reference except optionally its last owns exactly one constant positive length, and its last length is in (0,stride], so a signed, already-admitted r24 S_CHUNKS range can locate its first intersecting reference arithmetically, without building O(N) Python offsets or validating less?
For a late (>=half-file) 16-byte selective request on exact signed 65,536 and 262,144 reference archives, predict >=2.0x whole read_range wall speedup over the unchanged Reader range loop both on one-owner and on 256-owner, equal-length, held-out data. At Q=1 early range and nonuniform/ragged references, predict no >5% measured slowdowns. A result on one-owner only is weaker structural evidence, not a general product win. Relative CPU should agree in direction; no >8MiB RSS increase in any measured process. If proof/setup cost cancels the late-read win or creates hostile mismatch, retire the route (the baseline may win).

## Mechanism, controls, alternative
Do not modify the native `scan_refs` admission predicate, original strict Python validator, index hashes, archive bytes, recovery, extraction, public API or frozen test contracts. Add a separate limited-ABI witness method, lazily invoked *only* for sufficiently late S_CHUNKS selective range and cached per Reader/member, with constant-size witness (stride integer or negative). Verify every ref is an exact non-bool integer in bounds and every physical length is exact positive; calculate full reference total without overflow; fail closed unless declared size and signed list agree. The ordinary Reader constructor already validates the same index. A uniformly-sized prefix with a smaller nonzero last item is accepted; zero, mixed interior lengths, boolean, oversized indexes, and all irregular forms fall back to inherited `read_range`. C absence or exception also falls back; no trust in witness from a separately reopened pathname. Do not persist a stale cross-Reader/global cache or skip the mandatory full semantic admission.
Strong simpler controls: original linear read_range, O221 eager/lazy prefix checkpoints (their Q4 negative cannot be erased), and generic CDC read_range (must not be altered). A signed physical codec still goes through `_blob` / existing bounds and integrity; shortcut cannot mean fewer bytes authenticated.
