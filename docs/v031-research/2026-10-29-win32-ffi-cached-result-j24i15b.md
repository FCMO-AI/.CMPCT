## Reversal, causal interpretation and strongest self-critique
**One-line experimental architecture improvement reversed the scientific cost conclusion** from +97% to -23.3% vs correct reference, on two source families, with original historical negative preserved. The structural mechanism is cached FFI declarations/dispatch vs rebuilding ctypes classes and DLL signatures on each member. The two result-bearing runs are **different host invocations** and must not be treated as a quantitatively controlled before/after speedup due solely to the cache; each A/B pair inside its own run supports its own scoped conclusion. The current cached instrument offers good *micro-level* headroom, not integrated source-tree product credit.

The strongest unsolved safety negative is **ancestor/parent junction or symlink pivot**: `CreateFileW(FILE_FLAG_OPEN_REPARSE_POINT)` only guarantees no-follow behavior for the *last component*, not a stable root traversal, protected parent directories, an immutable inode after open, or atomic file content snapshots. PR #407 O52 demonstrates a POSIX parent pivot; #434 O77 evaluates genuinely rooted Linux controls. This Windows result also doesn't establish 128-bit ReFS file identity, SMB/network shares, NTFS same-source concurrent mutation, sparse CDC/virtual ZIP/xattr/deferred capture, full Builder time/RSS/temporary I/O, native core, recovery, crash safety or release parity.
