## Reproducciones y límites

La copia local de main se obtuvo con `git archive 80c358f8`, sin checkout de
otras ramas ni cambios al registro compartido de worktrees. Se comprobó además
identidad byte a byte de los manifiestos, workflows y fuentes citados.

1. **Manifiesto:** `python3 -m experiments.entropygraph_v030_release_lock_strict
   --print-fingerprint` devuelve 1 en ambos árboles, con el mismo mensaje.
   `docs/V030_RELEASE_LOCK.json` contiene `publication_mode=rolling-pre1-checkpoint`
   y `required_receipts=[]`; el loader estricto no admite esa combinación.
   Son nueve jobs afectados: dos fallan con stdout redirigida y siete publican
   la excepción. Los verdes de principios de octubre no acreditan este contrato actual.
2. **Suite heredada:** sin pytest se cargaron con `importlib.util` los cuatro
   módulos citados en `test` y se invocaron sus funciones de aserción sin fixtures.
   Se observaron los cuatro rojos en main. Esto no cuenta como suite completa.
3. **Sitio:** `site/build_site.py --out <salida-temporal>` seguido de
   `site/enhance_site.py <salida-temporal>`, en ambos árboles. El JSON resultante
   conserva evidencia `0.29.0` frente al proyecto `0.30.0`.
4. **Núcleo:** se ejecutó el `native_codec.py` real mediante un spec de importlib,
   sin importar el inicializador del paquete, para no confundir MessagePack ausente
   con el fallo nativo. En base y rama, sin bloqueo y bloqueando cada import de
   numpy/soundfile, se obtuvo `package-owned cmpct_core codec library is missing`;
   **cero intentos de importar audio** en los seis casos. Faltan los extras reales
   y la biblioteca: no se afirma haber cargado exitosamente el núcleo con extras instalados.
5. **Compilación real:** `CARGO_HOME="$PWD/.scratch/cargo" cargo build --offline
   --locked --release --manifest-path native/cmpct-core/Cargo.toml` devuelve 101:
   `flate2` no está en la caché. No se instalaron dependencias ni se usó la red.
6. **Audio #538:** se volvió a ejecutar la misma batería existente contra main
   y rama, con `benchmarks/diagnostic_zstd_adapter.py` y MessagePack vendorizado.
   Main: 5 métodos, 1 fallo y 3 errores (incluidos los subcasos numpy/soundfile).
   Rama: 5/5 pasan. No se alteraron aserciones. Son pruebas de flujo con Zstd
   ambiental, no aceptación del paquete ni cierre externo de #538.
7. **Harness:** `python3 -m unittest discover -s tests -p test_cold_archive_bench.py
   -v`: **6/6 pasan**, sin sustituciones. Incluye fallo del primer proceso del pipe.
8. **Índice:** los cinco métodos existentes pasan con el adaptador diagnóstico,
   sin skips. El control ganador usa la CLI Zstd independiente; no acredita el runtime propio.
9. **Controles heredados:** el ZIP inválido falla igual en ambos árboles con el
   adaptador; la frontera `CMPNX*` rechaza `research-only` al ejecutar sus funciones
   reales aisladas. No se ejecutaron los benchmarks OOXML/r25 completos.

`CMPCT_DIAGNOSTIC_SOURCE=<copia-main>/src` selecciona el motor base en el primer
comando manteniendo la batería del candidato. El adaptador anuncia la sustitución;
no debe usarse en una puerta de promoción.

Reproducción del cargador nativo sin sustituirlo (sólo biblioteca estándar):

```sh
python3 - src/cmpct .scratch/ci565-main/src/cmpct <<'PY'
import builtins, importlib.util, sys
from pathlib import Path
from unittest.mock import patch

original = builtins.__import__
for package in map(Path, sys.argv[1:]):
    for missing in (None, 'numpy', 'soundfile'):
        audio_imports = []
        def checked(name, *args, **kwargs):
            if name.split('.')[0] in ('numpy', 'soundfile'):
                audio_imports.append(name)
                if name.split('.')[0] == missing:
                    raise ModuleNotFoundError(name)
            return original(name, *args, **kwargs)
        spec = importlib.util.spec_from_file_location('probe', package / 'native_codec.py')
        module = importlib.util.module_from_spec(spec)
        with patch('builtins.__import__', side_effect=checked):
            try:
                spec.loader.exec_module(module)
            except RuntimeError as error:
                assert str(error) == 'package-owned cmpct_core codec library is missing'
                print(package, missing, error)
            else:
                raw = b'native codec roundtrip' * 32
                assert module.decompress(module.compress(raw, 3), len(raw)) == raw
                print(package, missing, 'núcleo cargado y roundtrip exacto')
        assert not audio_imports
PY
```

El mensaje de biblioteca ausente reproduce el rojo; sólo la rama `else` acreditaría
carga y operación nativas. En esta sesión no se alcanzó esa rama.

La aceptación solicitada `python3 -m pytest tests/test_optional_audio.py
tests/test_cold_archive_bench.py tests/test_cold_index_window.py -q` se intentó:
**código 1, `No module named pytest`**. Quedan UNVERIFIED la batería con el núcleo
propio, la carga exitosa con extras reales, la suite completa y los benchmarks
emparejados. Los 798 verdes y cuatro rojos son el conteo histórico de cada job CI,
no un resultado de suite local.

## Decisión y continuación

No se encontró un defecto adicional del motor introducido por el PR que justifique
otro cambio de código. Se preserva el fix #538. Los dos rojos causados por el PR
son una premisa incompatible del diagnóstico y un estado remoto de revisión que
contradice la deuda declarada. Se mantienen abiertos: no se desactiva una compuerta,
no se debilita una aserción y no se marca evidencia inexistente como cumplida.

`NEEDS.md`, sección `cmpct-ci565`, enumera las acciones exactas del integrador.
Esta investigación no publica una versión, no cambia formatos/ABI ni afirma un
milestone de rendimiento. La campaña CMPCT conserva su deuda de custodia, contexto
de perfiles, runtime base y demostración directa de rendimiento.
