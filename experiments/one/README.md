## ONE-G0.1 mission lock

**Question:** can one small generic reconstruction algebra express explicit Surprise, exact reuse/slicing, repetition/sparse regions, bounded arithmetic/delta relationships and multi-parent reconstruction without reader-visible legacy codec categories?

**Hypothesis:** six generic bulk operations (`surprise`, `concat`, `repeat`, `fill`, `xor`, `add8`) are sufficient for the first universal-derivation proof while keeping deterministic/resource semantics small enough to independently audit.

**Disproof:** reform the IR before adding compression search if conformance requires historical codec opcodes, if control structure is already comparable to the mechanism zoo, or if hostile programs cannot be rejected with static declarations plus bounded execution.

`ir.py` defines the semantic objects and hard resource declarations. `vm.py` is the deliberately simple reference evaluator. It is not a production codec and makes no compression-ratio claim.

The current conformance vectors live under `tests/one/`. They are hand-derived rather than generated by the evaluator, so builder/reader agreement is not the only oracle.
